LETTRE D'AMOUR — PAGE WEB + MODÈLE D'E-MAIL

Fichiers :
- index.html : la page interactive avec l'enveloppe animée.
- email-envelope.png : l'image à afficher dans le message e-mail.
- email-template.html : modèle HTML d'e-mail compatible avec les clients courants, à adapter.

IMPORTANT :
1. Hébergez le dossier sur un hébergeur web HTTPS public (par exemple GitHub Pages).
2. Remplacez dans email-template.html les deux occurrences de https://VOTRE-SITE-PUBLIC par l'adresse publique du site.
3. L'image et le lien doivent être publics et accessibles sans connexion.
4. Les services de messagerie ne permettent généralement pas d'exécuter JavaScript dans le corps du mail : le clic ouvre donc index.html dans le navigateur.
5. Pour envoyer le modèle, copiez son contenu HTML dans un outil d'envoi qui accepte les e-mails HTML. Si vous utilisez Gmail, vous pouvez envoyer un message normal avec un texte et un lien, ou passer par un outil d'envoi HTML.
